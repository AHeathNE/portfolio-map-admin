This page needs to be running through its server

It looks like this file was opened directly in the browser (the address bar doesn't say localhost). The admin needs its small Python server running to read and save anything. From a terminal, in the admin folder, run: 

python3 server.py

Then open the address it prints — usually http://localhost:8420 — instead of double-clicking this file.

Point the admin at a site folder

This admin edits the data behind a portfolio map site — but it isn't pointed at one yet. Enter the path to an existing site folder, or an empty folder to start a brand new site there.
